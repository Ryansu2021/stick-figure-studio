# 黑板火柴人短片工作台 (Studio v2.7)

教師研習用的純前端工具：先向 AI 索取動畫腳本，再貼回網頁，直接在瀏覽器渲染並匯出 9:16 黑板風火柴人數學短片。

**線上使用：** https://ryansu2021.github.io/stick-figure-studio/

## 使用流程

| 步驟 | 說明 |
|---|---|
| 1. 取得提示詞 | 點右上角「第一步」，複製提示詞並修改主題後貼給 AI |
| 2. 貼上腳本 | 將 AI 產生的 JavaScript 貼入工作台，自動解析時長與台詞 |
| 3. 選擇配樂 | 內建合成音、靜音，或上傳自己的 MP3／WAV |
| 4. 渲染匯出 | 一鍵逐格渲染，並下載 MP4 或 WebM（依瀏覽器支援而定） |

## 其他功能

- v2.7：大標題、副標題、左上小標依字數自動縮小字級，過長時壓縮字距，不會再被切掉；提示詞新增「大標題最多 9 字」規則

- 內建「三角形 SSA 為什麼不一定全等」示範腳本
- 9:16 黑板放映室與影格抽檢時間軸
- 以 HTML5 Canvas 與 Web Audio 運作，音訊與影片都在瀏覽器內處理
- 樣式已內嵌於單一 HTML，下載 `index.html` 後即可斷網開啟與出片（向 AI 索取腳本的步驟仍需網路）
